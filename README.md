# Minecraft Fabric Mod

This Minecraft mod adds a copper and iron alloy called burnt brass, along with two crafted weapons: a longsword and a massive axe. The provided project files currently implement beetle brass made from copper and netherite, so the alloy and weapon recipes described here follow the implementation.

## Install

1. Install Minecraft 1.21.1 with Fabric Loader 0.16.5 or newer and Fabric API.
2. Use Java 21.
3. Build the project from its root with `./gradlew build`.
4. Put the generated mod jar from `build/libs` into your Minecraft `mods` folder.
5. Launch the Fabric profile.

## Use

1. In a crafting table, combine one copper ingot and one netherite ingot to make two Beetle Brass.
2. Arrange Beetle Brass and a stick in the crafting table to craft the Beetle Brass Longsword or Great Axe.
3. Repair either weapon with Beetle Brass.
